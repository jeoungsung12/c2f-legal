온새미골 계정과 그 계정에 연결된 데이터를 지우는 방법입니다. 앱 안에서 바로 지울 수 있고, 앱을 지웠다면 이메일로 요청할 수 있습니다.

1. 앱에서 바로 삭제하기

  1. 온새미골 앱을 열고 설정을 엽니다.
  2. 계정 · 데이터 > 계정 삭제를 누릅니다.
  3. 안내를 읽고 [확인]을 누른 뒤, 입력 칸에 삭제라고 쓰고 다시 [확인]을 누릅니다.
  4. 로그인한 계정(Android 는 Google 계정, iPhone 은 Apple 계정)으로 한 번 더 확인합니다.
  5. "계정을 지웠어요" 가 뜨고 처음 화면으로 돌아가면 끝입니다.

인터넷 연결이 필요합니다. 중간에 연결이 끊기면 다음에 앱을 열 때 남은 단계를 이어서 진행합니다.

2. 앱 없이 삭제 요청하기

앱을 이미 지웠거나 앱에서 삭제가 끝나지 않을 때는 이메일로 요청해 주세요.

  • 받는 곳: onsaemigol@gmail.com
  • 제목: 계정 삭제 요청
  • 본문: 로그인에 쓴 Google 계정의 이메일 주소. Apple 로 로그인했다면 게임 닉네임과 마지막으로 플레이한 날짜.

로그인에 쓴 그 이메일 주소에서 보내 주시면 본인 확인이 빠릅니다. 본인 확인이 필요하면 회신으로 몇 가지를 더 여쭐 수 있습니다. 요청을 받은 날부터 10일 안에 삭제하고 결과를 회신합니다.

3. 지워지는 데이터

데이터언제 지워지나
계정 식별자(uid)와 로그인 연결, 로그인 기록에 남은 Google 계정의 이메일 주소·이름·프로필 사진 주소즉시
닉네임, 클라우드(구름 저장)에 백업한 게임 기록즉시
이 기기에 저장된 게임 기록앱에서 삭제하면 즉시. 앱을 지우면 함께 지워집니다
사용 통계 식별자앱에서 삭제하면 즉시 초기화

4. 남는 데이터와 보관 기간

아래 데이터는 계정과 연결되지 않은 기록이라 계정 삭제 뒤에도 정해진 기간 동안 남았다가 자동으로 지워집니다.

데이터보관 기간
사용 통계 (진단·사용 통계 전송에 동의한 경우만, 가명 식별자 기준)가명 식별자에 묶인 기록은 최대 2개월 뒤 자동 삭제. 개인을 알아볼 수 없는 집계 수치(예: 하루 이용자 수)는 남을 수 있습니다
오류 보고 (같은 동의를 한 경우만)최대 90일 뒤 자동 삭제
Firebase 설치 ID (설정값 배포·앱 위변조 확인용)앱을 지우면 더 쓰이지 않고 Google 서비스 처리 기간이 지나면 삭제

결제 기능이 없어 법령에 따라 따로 보관하는 데이터는 없습니다.

5. 로그인하지 않고(게스트로) 플레이했다면

서버에 계정 데이터가 없습니다. 앱 설정 > 계정 · 데이터 > 로컬 초기화를 누르거나 앱을 지우면 기기의 게임 기록이 지워집니다.

6. 로그인 연결만 끊고 싶다면

계정 삭제와는 별도로, Google 계정 관리의 보안 메뉴에 있는 '타사 앱 및 서비스와의 연결' 목록에서 온새미골 연결을 끊을 수 있습니다. iPhone 은 설정 앱의 Apple 계정에 있는 'Apple로 로그인' 목록에서 끊을 수 있습니다.
